# سراقب ستور — أساس النظام الخلفي

## ما الذي أصبح جاهزاً؟
- إنشاء حساب وتسجيل دخول بكلمات مرور مشفّرة.
- حساب رصيد منفصل لكل مستخدم بالدولار.
- طلبات شحن رصيد بحالات انتظار/مقبول/مرفوض.
- اعتماد طلب الشحن من لوحة الإدارة عبر API.
- سجل معاملات ورصيد.
- عرض منتجات وإضافة منتجات من صلاحيات الإدارة.
- إنشاء طلب شراء يخصم من رصيد الزبون ويضع الطلب في مراجعة يدوية.
- حالات الطلب: قيد المراجعة، قيد التنفيذ، مكتمل، مرفوض.

## ما الذي لم يتم تفعيله؟
- لا يوجد اتصال فعلي بمزود ياسين كارت حتى الآن.
- لا توجد بوابة دفع إلكترونية؛ إثبات التحويل ومراجعته يدويان.
- واجهات API موجودة، لكنها تحتاج ربط الواجهة الأمامية بها.
- يلزم اختبار أمني وتشغيلي قبل استقبال أموال حقيقية.

## تشغيل محلي
1. ثبّت Python.
2. نفّذ: `pip install -r requirements.txt`
3. اضبط متغيرات البيئة من `.env.example` (لا ترفع ملف الأسرار إلى GitHub).
4. شغّل: `python app.py`
5. فحص الحالة: `/api/health`

## النشر
استخدم PostgreSQL مُداراً وضع رابط الاتصال في `DATABASE_URL`. لا تستخدم SQLite على استضافة ذات نظام ملفات مؤقت لمتجر يحفظ أرصدة العملاء.
عيّن `SECRET_KEY` و`ADMIN_USERNAME` و`ADMIN_PASSWORD` في إعدادات الاستضافة. لا تضع أسرار API في ملفات الواجهة أو GitHub.

## ملاحظة مهمة
هذا أساس تقني أولي وليس نظاماً مالياً جاهزاً للإنتاج. يجب إضافة حماية CSRF/حدود محاولات الدخول وسجل تدقيق ونسخ احتياطي واختبار الاسترجاع، ثم ربط واجهة الموقع واختبار العمليات قبل تفعيل الدفع.
